# HK ELI Chatbot docs

Start here before changing anything. Read in this order:

1. [business-vision.md](business-vision.md): the vision, business objective (measurable uplift by end 2029 against an Oct to Dec 2026 baseline), who it serves, scope, success metrics and the seven guiding principles.
2. [decisions.md](decisions.md): the stakeholder answers and the product and technical decisions made since discovery. These win over anything older.
3. [discovery.md](discovery.md): personas, the launch-user product approach, journeys, needs, requirements R1 to R41, insights, open questions.
4. [reference/unusual-whales-trade-finder-review.md](reference/unusual-whales-trade-finder-review.md): the outside product the Ideas flow learns from (behind R27 to R35).

How the code maps to this: [`web/`](../web/README.md) is the Angular widget, [`gateway/`](../gateway/README.md) the Java service.

The vision and discovery files are copies of live Claude Docs (links at the top of each). When one of those docs changes, update the copy here in the same change, keeping this public version free of people's names, business-case figures and internal deck figures.
